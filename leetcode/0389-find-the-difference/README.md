## Problem Statement

<p>You are given two strings <code>s</code> and <code>t</code>.</p>

<p>String <code>t</code> is generated by random shuffling string <code>s</code> and then add one more letter at a random position.</p>

<p>Return the letter that was added to <code>t</code>.</p>

## Constraints

- <code>0 &lt;= s.length &lt;= 1000</code>
- <code>t.length == s.length + 1</code>
- <code>s</code> and <code>t</code> consist of lowercase English letters.

## Solution

```py
class Solution(object):
    def findTheDifference(self, s, t):
        temp = list(s)
        for ch in t:
            if ch in temp:
                temp.remove(ch)
            else:
                return ch
```
